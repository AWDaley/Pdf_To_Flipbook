# NASA photograph

`nasa-iss064-e-9397.jpg` is NASA astronaut photograph **ISS064-E-9397**, acquired December 3, 2020 by an Expedition 64 crew member. It shows Lake Tahoe, Walker Lake, and Mono Lake. NASA attributes it to the ISS Crew Earth Observations Facility and the Earth Science and Remote Sensing Unit, Johnson Space Center. The supplied NASA image was already cropped and enhanced; our magazine contains a further rectangular layout crop, with no scientific interpretation added.
