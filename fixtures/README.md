# Rights-cleared fixtures

Writing, layout, and landscape/botanical/architectural illustrations in this folder and public/demo are original material generated by scripts/generate-fixtures.mjs for this repository. The repository owner may use, modify, and redistribute that original material with the application. Page 6 adds credited NASA astronaut photography; see assets/README.md for its verified official source and usage guidelines. No Heyzine publication or player assets are included.

- fieldnotes.pdf: 10-page editorial magazine, real PDF text, original rasterized vector illustrations, NASA photograph.
- pages-1/2/5/6.pdf: source count and odd/even ending fixtures.
- image-only.pdf: one raster page with no extracted text.
- mixed-rotation-crop.pdf: portrait, landscape, square, 90/270-degree rotation, cropped MediaBox.
- links-bookmarks.pdf: supported HTTPS and page links, unsafe javascript/file links, outline targeting page 3.
- fine-text.pdf: small text and fine strokes.
- malformed.pdf: deliberately invalid input.
- password-required.pdf: AES-256 encryption; test password fixture-password.

Regenerate artwork and ordinary fixtures with npm run fixtures; the checked-in photograph is used locally and regeneration makes no network request. Regenerate the password fixture with python scripts/generate-password-fixture.py (pypdf and cryptography required only for this fixture operation). Python is not an application dependency.
