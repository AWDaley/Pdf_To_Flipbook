Paperbound exported flipbook

This folder is a read-only snapshot, not an editable project backup.
For the simplest viewing experience, unzip the folder and double-click index.html. It opens in Chrome or Edge without Node or a terminal.
If your browser blocks local files, open a terminal in this folder and run the included dependency-free Node server:
node serve.mjs . 8080
Then open http://127.0.0.1:8080/ and press Ctrl+C to stop.
You can also serve the entire folder with any static server or static host.
All reader resources are local; the creator service and internet are unnecessary.
Subdirectory hosting is supported. External document links need a network only when you choose to follow them.
The original PDF is included only when selected during export.
