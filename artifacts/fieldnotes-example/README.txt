Paperbound exported flipbook

This folder is a read-only snapshot, not an editable project backup.
Open a terminal in this folder, then run the included dependency-free Node server:
node serve.mjs . 8080
Open http://127.0.0.1:8080/ in a browser. Press Ctrl+C to stop.
Node is already installed if this computer runs Paperbound Studio.
You can also serve the entire folder with any static server or static host.
All reader resources are local; the creator service and internet are unnecessary.
Subdirectory hosting is supported. Double-clicked file:// pages are not supported.
External document links need a network only when you choose to follow them.
The original PDF is included only when selected during export.
